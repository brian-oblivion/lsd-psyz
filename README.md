# lsd-psyz

A fork of [psyz](https://github.com/Xeeynamo/psyz), used by the PC port of LSD: Dream Emulator ([lsd-port](https://github.com/brian-oblivion/lsd-port)). I try to stay close to upstream and send my fixes back as pull requests.

For everything else, see the [upstream README](https://github.com/Xeeynamo/psyz#readme).
